About the Project

EduStay is a smart student accommodation platform built to connect university students with verified property owners. Students can browse accommodations, book rooms, make secure payments, rate their stay, and communicate directly with owners — all from a single mobile application. The platform solves the real-world problem of finding safe, affordable, and conveniently located student housing.

Key Features
  • Browse & search properties by location, price, and amenities
  • Smart booking system with automatic price calculation
  • Secure payments (cash / card)
  • In-app chat between students and owners
  • Property reviews and ratings
  • Save favorite properties
  • WhatsApp integration for direct contact
  • Support ticket system
Tech Stack
Laravel 12 PHP 8.2 MySQL Flutter Dart Sanctum Auth REST API
عن المشروع

إيدو ستاي هي منصة ذكية لإسكان الطلاب تم بناؤها لربط الطلاب الجامعيين بأصحاب العقارات الموثوقين. يمكن للطلاب تصفح أماكن السكن، حجز الغرف، إجراء المدفوعات الآمنة، تقييم إقامتهم، والتواصل مباشرة مع المالكين — كل ذلك من خلال تطبيق جوال واحد. تحل المنصة مشكلة حقيقية تتمثل في إيجاد سكن طلابي آمن وبأسعار معقولة وفي مواقع مناسبة.

المميزات الرئيسية
  • تصفح العقارات والبحث حسب الموقع والسعر والمرافق
  • نظام حجز ذكي مع حساب تلقائي للأسعار
  • مدفوعات آمنة (نقداً / بطاقة)
  • محادثة فورية بين الطلاب والمالكين
  • تقييمات ومراجعات للعقارات
  • حفظ العقارات المفضلة
  • التكامل مع واتساب للتواصل المباشر
  • نظام تذاكر للدعم الفني
